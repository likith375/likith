# Training-data inbox

Drop your own text-based training material here:

- `.jsonl`, `.json`, `.csv`
- `.luau`, `.lua`
- `.txt`, `.md`

Then open NeuralForge → Datasets → **Import data/inbox folder**.

The importer treats every file as data only. It does not run scripts. Files are limited to 15 MB each. Re-importing an unchanged file is skipped automatically. Structured files should use the dataset format documented in `docs/dataset-format.md`.
