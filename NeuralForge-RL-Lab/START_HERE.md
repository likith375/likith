# Start NeuralForge without installing Python locally

This repository includes a GitHub Codespaces development-container setup.

1. Open the NeuralForge-RL-Lab folder in the GitHub repository.
2. Choose **Code → Codespaces → Create codespace on main** (if Codespaces is available on your GitHub account).
3. Wait for the environment to install dependencies and start the server.
4. Open the forwarded port 8000 named **NeuralForge RL Lab**.

Codespaces availability and free usage depend on your GitHub account quota and billing settings. The first version is a functional workflow MVP in demo mode; it does not train neural-network weights until you connect a compatible Python model adapter.
