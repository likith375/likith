Adapter configuration

Use backend.hf_adapter:load_adapter for the built-in local Hugging Face adapter, or adapters.custom_adapter:load_adapter after replacing the template with your own model integration. Install requirements-ml.txt for the Hugging Face option.

Adapter contract

  1. generate(prompt, context)Return the model's generated Luau text.
  2. train_step(batch)Perform a real optimizer update using response rewards.
  3. save_checkpoint(path)Persist model weights and optimizer state.
  4. load_checkpoint(path)Restore the saved model state.
