# NeuralForge RL Lab

NeuralForge RL Lab is a local-first, domain-independent AI training laboratory. It connects to your own Python model through an adapter, imports datasets and documents, builds tasks, supports supervised and reward-based updates, stores reviewed corrections and human feedback, runs benchmarks, and saves model checkpoints.

**Open the software project:** [NeuralForge-RL-Lab](NeuralForge-RL-Lab/)

Start with [`NeuralForge-RL-Lab/START_HERE.md`](NeuralForge-RL-Lab/START_HERE.md) for setup, then read the [scratch-built AI adapter guide](NeuralForge-RL-Lab/docs/custom-adapter-guide.md) to connect your model.
